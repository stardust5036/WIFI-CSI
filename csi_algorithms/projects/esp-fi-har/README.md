## Algorithm boundary

The repository is a CSI human-activity dataset/model package. The public
layout confirms amplitude recordings and trained-model experiments, but a
specific raw packet decoder and production inference path were not verified
from the checked tree. It is useful for training-data comparison, not for
claiming a fixed embedded presence algorithm.
