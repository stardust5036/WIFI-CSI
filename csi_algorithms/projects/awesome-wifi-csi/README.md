# Awesome WiFi CSI Sensing

- **Source:** [NTUMARS/Awesome-WiFi-CSI-Sensing](https://github.com/NTUMARS/Awesome-WiFi-CSI-Sensing)

## Project scope

This is an index of Wi-Fi CSI sensing papers and projects. It is useful for
discovering additional datasets, activity-recognition methods, occupancy
systems, and code repositories.

## Algorithm boundary

An index entry is not validation of an algorithm. Each candidate must be
checked in its own paper and repository, especially for CSI hardware,
sampling rate, labels, and train/test split.
