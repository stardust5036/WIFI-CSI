# ESP32-CSI-Tool

- **Source:** [StevenMHernandez/ESP32-CSI-Tool](https://github.com/StevenMHernandez/ESP32-CSI-Tool)

## Project scope

This is primarily an ESP32 CSI acquisition and export project. It is useful
for studying CSI collection, packet formats, and host-side processing.

## Algorithm boundary

It should not be described as a complete presence classifier without checking
the specific branch and processing scripts. Collection and decoding are
separate from presence/motion inference.
