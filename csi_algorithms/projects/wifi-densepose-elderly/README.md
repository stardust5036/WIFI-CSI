## Raw CSI -> result

The public repository does not expose a verified raw-CSI decoder in the
checked files. Its visible path is service/API pose output and simulated
fall/lying events. Therefore no raw-IQ-to-fall algorithm is claimed here.
The directory is retained as a project lead, not as evidence for the current
ARMv7 detector.
