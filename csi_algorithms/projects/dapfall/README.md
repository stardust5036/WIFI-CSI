## Raw CSI -> result

The project describes a Dynamic Amplitude Probability Density Profile
approach for Wi-Fi CSI fall detection. The essential flow is amplitude
sequence -> dynamic distribution/profile -> learned or thresholded fall
decision. Exact training data and model configuration must be pinned before
deployment.
