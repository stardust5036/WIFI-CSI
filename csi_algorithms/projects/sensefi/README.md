# SenseFi

- **Source:** [WiFi-CSI-Sensing-Benchmark](https://github.com/xyanchen/WiFi-CSI-Sensing-Benchmark)
- **Paper:** [arXiv:2207.07859](https://arxiv.org/abs/2207.07859)

## Project scope

SenseFi is a benchmark/library for comparing deep-learning models on Wi-Fi
sensing datasets. It is useful for offline experiments with CNN, recurrent,
and related models.

## Algorithm boundary

It is not an embedded ARMv7 standard and does not establish that a model will
run on the current UDP receiver. Use it as a dataset/model comparison project,
not as evidence about the Espressif firmware algorithm.
